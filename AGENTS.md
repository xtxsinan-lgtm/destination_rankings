# Workspace Rules (`AGENTS.md`)

## Mandatory Auto-Push Rule
- **Every time** you create, edit, or update any file in this repository (HTML, JS datasets, Markdown rankings, images, or scripts), you **MUST** automatically run `git add -A`, `git commit -m "..."`, and `git push origin HEAD` before ending your turn.
- Never wait for the user to ask "did you push?". Always follow the [`auto-git-push`](.agents/skills/auto-git-push/SKILL.md) skill and include the pushed commit hash in your final reply.
